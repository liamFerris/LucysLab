# Module 14: What's wrong?

*Intra-oral film faults and quality assessment*

## What you should be able to do

- Explain how intra-oral image quality is assessed and rated.
- Describe the main causes of digital image and film faults.
- Recognise the common digital image and film faults.
- Explain how to correct the common digital image and film faults.

## Quality criteria for intra-oral radiographs

### Periapical quality criteria

- <mark>Crown and entire root</mark> of the tooth/teeth under investigation included on the image.
- <mark>Apical tissues clearly defined</mark>, including the full extent of any disease present.
- Minimal vertical geometrical distortion in tooth/teeth length.
- No overlapping.
- No unwanted superimposition of adjacent structures.
- Contrast and density should be such that <mark>enamel, dentine and pulp can be differentiated</mark>.

### Bitewing quality criteria

- <mark>Occlusal plane in the middle of the image</mark> and parallel to the top and bottom of the image.
- <mark>Distal aspect of the canines to the mesial aspect of the third molars</mark> included on the image.
- Crowns, necks and coronal third of the roots of all the teeth clearly defined.
- No vertical geometrical distortion.
- <mark>All contact areas clearly showing with no overlapping.</mark>
- Contrast and density should be such that enamel, dentine and pulp can be differentiated and the <mark>EDJ (enamel–dentine junction) can be clearly visualised for caries diagnosis</mark>.

## Subjective quality rating of radiographs

| Quality | Basis of decision |
|---|---|
| <mark>A – Diagnostically acceptable</mark> | No errors or minimal errors in either patient preparation, exposure, positioning, image processing or image reconstruction, and of sufficient image quality to answer the clinical question. |
| <mark>N – Diagnostically not acceptable</mark> | Errors in either patient preparation, exposure, image processing or image reconstruction which render the radiograph diagnostically unacceptable. |

## Minimum targets for radiographic quality

### Digital radiographs

| Quality | Percentage of radiographs taken |
|---|---|
| A | <mark>Not less than 95%</mark> |
| N | <mark>Not greater than 5%</mark> |

### Film radiographs

| Quality | Percentage of radiographs taken |
|---|---|
| A | <mark>Not less than 90%</mark> |
| N | <mark>Not greater than 10%</mark> |

## Digital image faults and errors

| Fault or error | Corrective action |
|---|---|
| **<mark>Image too dark: over-exposed</mark>** | |
| Incorrect timer setting | Adjust setting |
| Faulty timer | Organise service and repair |
| **<mark>Image too pale: under-exposed</mark>** | |
| Incorrect timer setting | Adjust setting |
| Faulty timer | Organise service and repair |
| Failure to keep timer depressed | Repeat correctly |
| **<mark>Unsharp or blurred image</mark>** | |
| Patient movement | Re-instruct patient |
| **<mark>Image marked</mark>** | |
| Phosphor plate scratched | Repeat using new plate |
| Phosphor plate dirt | Clean and repeat |
| Image receptor back-to-front | Repeat correctly |
| Solid-state sensor cracked | Repeat using new sensor |
| **<mark>Distorted/compromised by poor preparation and/or positioning</mark>** | |
| Failure to remove denture/appliance | Remove and repeat correctly |
| Elongation/foreshortening/overlapping | Use beam-aiming device |
| Coning off or cone cutting | Use beam-aiming device |

## Intra-oral film faults and errors

### Exposure and processing faults

| Fault or error | Corrective action |
|---|---|
| **<mark>Film too dark: overexposed</mark>** | |
| Incorrect timer setting | Adjust setting |
| Faulty timer | Organise service and repair |
| **<mark>Film too dark: overdeveloped</mark>** | |
| Developer too hot | Check temperature and adjust |
| Developer concentration too high | Dilute or change chemicals |
| Development time too long | Adjust as necessary |
| **<mark>Fogged by light</mark>** | |
| Light leakage | Check processor/darkroom |
| **<mark>Film too pale: underexposed</mark>** | |
| Incorrect timer setting | Adjust setting |
| Faulty timer | Organise service and repair |
| Failure to keep timer depressed | Repeat correctly |
| **<mark>Film too pale: underdeveloped</mark>** | |
| Developer too cold | Check temperature and adjust |
| Developer too dilute | Change chemicals |
| Developer exhausted | Change chemicals |
| Development time too short | Adjust as necessary |
| **<mark>Technique error</mark>** | |
| Film back to front | Repeat correctly |

### Blurring, marks and positioning faults

| Fault or error | Corrective action |
|---|---|
| **<mark>Unsharp or blurred film</mark>** | |
| Patient movement | Re-instruct patient |
| Excessive bending of film packet | Handle more carefully and re-instruct patient |
| **<mark>Film marked: handling error</mark>** | |
| Film packet excessively bent or creased by operator | Careful clinical handling |
| Careless handling in darkroom or automatic processor | Careful handling during processing |
| **<mark>Film marked: processing error</mark>** | |
| Chemical splashes | Careful chemical handling |
| Films stuck together | Careful handling |
| Insufficient chemicals | Check chemicals and adjust |
| Under-fixation | Change chemicals |
| **<mark>Film distorted/compromised by poor positioning and/or preparation</mark>** | |
| Back to front/double exposure | More careful handling |
| Elongation/foreshortening | Use beam-aiming device |
| Overlapping | Use beam-aiming device |
| Coning off or cone cutting | Use beam-aiming device |
| Failure to remove denture/appliance | Remove and repeat correctly |
